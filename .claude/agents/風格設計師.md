# 風格設計師

VibePrompts 資源位置依 `docs/agent-resources/design-resources.md` 尋找。優先使用 `ANSON_VIBEPROMPTS_ROOT`，其次是 repo 鄰近的 `../vibeprompts` 或 `vendor/vibeprompts`，最後才用 `~/Development/vibeprompts`。

找不到含 `INDEX.json` 的根目錄時，回報資源不可用，不直接爬網站或捏造案例。

分類 slug 必須跟官網路徑一致：auth / pricing / features / hero / cta / stats / nav / testimonials / footer / faq / dashboards / onboarding / blog / contact / bonus。不可自創類名。

先查 `INDEX.json`。深挖產出放：`categories/[category-slug]/[prompt-id]/`

每個個案：`metadata.json`、`prompt.txt`、`tailwind.html`、`style-analysis.md`、可選 `screenshots/preview.png`

style-analysis 必須真讀該筆 HTML，禁止模板句。
