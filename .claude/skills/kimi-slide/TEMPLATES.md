# Kimi 提詞模板

配合 `SKILL.md` 使用。本檔含中繼 md 格式範本、三種提詞模板的通用版本（Path A / Path B / 逐頁詳細規格版）。已驗證過的實際案例見 `knowledge/worked-examples.md`。

---

## 1. 中繼 md 格式範本（通用）

```markdown
# {單元/簡報名稱} — Kimi 簡報素材

- 主題：{一句話}
- 受眾：{身份/程度}
- 目的：{看完要做到什麼}
- 頁數：{N 頁}
- 語氣：{正式 / 口語化}
- 風格：{視覺調性}

## 逐頁重點
1. {頁面重點 一行}
2. ...
```

---

## 2. 提詞模板（通用版本）

### Path B（零散想法）

```
請幫我生成一份 {N} 頁的 PPT，主題是「{主題}」。
受眾是 {受眾}，目的是 {目的}。
風格：{風格}，語氣：{語氣}。
請依照以下重點分頁呈現：
1. {重點1}
2. {重點2}
...
```

### Path A（完整逐字稿）

```
我附上一份完整逐字稿/文案，請你閱讀後幫我生成一份約 {N} 頁的 PPT，主題是「{主題}」。
受眾是 {受眾}，目的是 {目的}。
風格：{風格}，語氣：{語氣}。
請特別著重呈現以下重點：{重點1}、{重點2}⋯（其餘內容請你自行判斷分頁與取捨）
```

### 逐頁詳細規格版（疊加在 Path A 或 Path B 之上）

對外正式場合、需要精確視覺控制時用。比上面兩版嚴格：強制 hex 色碼、指定字體、強制逐頁展開規則（不合併、不跳過、不摘要），每頁固定包含標題／重點文字／配圖建議。

```
請幫我製作一份 {N} 頁的專業簡報，主題是「{主題}」。

這份簡報的目標對象是 {受眾}，目的是 {目的}。

請嚴格遵守以下規則：

1. 這份內容共有 {N} 頁，請「一頁一頁」獨立生成，每一頁都是獨立的一張投影片。
2. 不要合併頁面、不要跳過任何一頁、不要只做重點摘要——{N} 頁都要完整產出。
3. 每一頁的設計請包含：
   - 核心標題與副標題
   - 重點文字（條列式或短句）
   - 搭配的圖片、Icon、架構圖或對照表建議
   - 每頁一個重點，保持簡潔、好讀、3-5 秒內能理解
4. 整體風格：{風格}，語氣：{語氣}
5. 設計規範：
   - 主色：{主色 hex}
   - 強調色：{強調色 hex}
   - 輔助色：{輔助色 hex，若無可省略}
   - 字體：{中文字體}、{英數字體}
6. 特別要求：{若有特定頁面需要加強視覺化呈現，標註頁碼與呈現方式；沒有則省略此項}

以下開始是 {N} 頁的逐頁內容：

---

## 頁 1｜{標題}

- 主標題：{主標題}
- 副標題：{副標題，若無可省略}
- 重點文字：{條列或短句}
- 配圖／Icon 建議：{一行描述}

---

## 頁 2｜{標題}

...（每頁比照頁 1 格式逐頁列到頁 {N}，不可合併、不可省略任一頁）
```

**若 {N} > 10**，提詞之外要額外提醒使用者這句續傳技巧：「如果 Kimi 沒有一次生成完整 {N} 頁，請告訴它：『繼續，從第 X 頁開始』。」
