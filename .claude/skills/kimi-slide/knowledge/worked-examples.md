## 4. 驗證範例 B — Path B（模擬情境，非真實檔案）

情境設定（模擬）：使用者只說「我想做一份給小工作室老闆看的簡報，講 AI 工具能幫忙省錢省時間，風格希望活潑一點、少文字多圖，但心裡會有點抗拒，沒有寫逐字稿，就幾個念頭」。沒有完整草稿 → **走 Path B**。

使用者已在原始描述裡主動提到風格偏好（活潑、少文字多圖），直接記入風格欄位、不重複問；依 SKILL.md 定義的 5 題依序問缺的欄位：

1. 主題是什麼？ → 「AI 工具如何幫小型工作室省時間省成本」
2. 受眾是誰？ → 「正在猶豫要不要導入 AI 工具的個人工作室 / 小型創業者」
3. 大概要幾頁，或預計講多久？ → 「大概 15 分鐘，抓 8 頁」
4. 語氣要正式還是口語化？ → 「口語化，像朋友聊天」
5. 有哪些重點一定要強調？ → 「省錢、省時間、心理障礙怎麼克服、需要具備的心態」
