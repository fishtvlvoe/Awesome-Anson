# 報價文件驗證

## 文字與數字

```bash
rg -n "報價對象|報價日期|有效期限|必要|非必要|加購|交付|驗收|時程|付款|保固|資安" deliverables/*.html
```

逐項重算：必要小計、非必要小計、基礎總價、加購小計；確認替代方案未被重複加總。

## HTML 與 PDF

- 用瀏覽器列印或專案指定工具輸出 PDF，確認 A4 分頁、表格不被截斷、中文字型正常、色彩與層級足夠清楚。
- 以 PDF 文字抽取或 `pdftotext` 檢查主要標題、金額與條款存在。
- 至少檢查一張總覽頁、一張價格明細頁、一張條款頁；必要時渲染成圖片目視確認。

## 回報分層

分開回報：原始檔驗證、PDF 產出、視覺檢查、測試／腳本、Git commit、GitHub remote。任何一層沒做都標成未驗證，不用「完成」一詞掩蓋缺口。
