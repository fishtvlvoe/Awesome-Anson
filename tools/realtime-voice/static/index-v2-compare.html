Anson realtime workbench · design review

三個 UI 方向，先看哪種順眼。

三個版本都維持同一個產品核心：左邊是「客戶 ↔ PM」對話，中間是 AI 即時分析，右邊是你直接指揮 AI 的輸入框。差別在資訊密度、氛圍與誰是畫面主角。

A / SIGNAL DESK

清楚、平衡、容易上手

淺色工作台。三欄權重平均，適合第一次使用或需要快速理解介面的 PM。

淺色三欄平均橘色提示
開啟設計 A
B / COMMAND ROOM

專注、沉浸、長時間工作

深色指揮台。降低背景干擾，把波形、狀態與 AI 指令變成長時間盯著看的工作畫面。

深色低干擾資訊監看
開啟設計 B
C / CONVERSATION FIRST

先看誰說的，再問下一句

對話優先。放大角色標籤與原話，適合訪談中最在意「客戶到底說了什麼」的 PM。

對話放大角色強識別指令突出
開啟設計 C

角色分別規則：客戶固定顯示「客戶｜姓名」與橘色；PM 固定顯示「PM｜姓名」與藍色；AI 不進入逐字稿，只在中間與右邊出現。遇到 Speaker 1／Speaker 2 時，先確認身份再寫入正式紀錄。
