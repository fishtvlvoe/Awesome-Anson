案件分析工具包 · 使用說明書

案神在幹什麼：把客戶的逐字稿，變成你敢拿去談判的報價單跟簡報。

案神（Awesome-Anson）做一件事：你把案子的資料丟給它，它交出一份你敢拿去跟客戶談的報價單和簡報。裡面分兩層——4 位「助理」接力處理需求、報價、簡報；9 個「工具」在背後被這些助理拿去用，你自己也可以單獨拿出來用。

它不會自己偷偷在背景跑。沒有人幫它排定時間表、沒有東西一直醒著等你——你叫它，它才動；你沒叫它，它就完全安靜，像個乖乖等你按門鈴才出現的管家。

讀法說明

這份說明書怎麼標記內容

案神教它的 PM 助理，把每一項需求標成「已確認 / 待確認 / 我猜的」三種狀態。這份說明書用同一套方法標記自己：對照原始檔案逐字核對過的，蓋「已確認」；還在規劃、尚未真的落地的，老實蓋「待確認」或「我猜的」，不裝作它已經是一個現成工具。

待確認 有明確規劃方向，還沒真正落地
我猜的 推測或尚未存在，需要 Fish 確認

助理

4 位助理：各做各的，互不知道對方在忙什麼

「助理」的意思是：它有一個固定的工作內容跟固定的做事方法，你點名找哪位助理，它就用那個角色的方式幫你做，不會做別的事——就像公司裡有人專門管報價、有人專門管簡報，職務分清楚。

project-manager

已確認

中文角色：專案管理與需求分析師

把客戶逐字稿、會議記錄整理成「已確認的需求」，交出一份下一位助理能直接接手的整理檔。它不自行承諾價格，也不把自己的推測寫成客戶已經決定的事。

  • 每一項需求都標「已確認 / 待確認 / 我猜的」
  • 交出去的檔名固定，方便接手：PM-TO-QUOTE-DATA-PACK.md
  • 案子複雜、資訊不夠時，會先用一個叫 pm-discovery-upgrade 的工具，一題一題問你，把缺的資訊補齊

commercial-proposal-quotation-specialist

已確認

中文角色：商務提案與報價顧問

把 PM 整理好的需求算成價格、寫成條款，變成客戶看得懂、金額可重算、責任邊界清楚的提案。先出網頁版給客戶看，客戶點頭才轉成正式 PDF。

  • 算價格的動作其實是一個叫 engagement-quote 的工具在背後跑，這位助理負責把結果包裝成你看得懂的提案
  • 轉 PDF 前一定先給你看過網頁版

簡報師

已確認

Presentation Manager Agent

開課師

已確認

Course Builder Agent · 旁支，跟接案報價無關

拿主題、素材跟講師經驗，走完六階段開課流程，交付課程綱要、簡報中繼稿、簡報輸出跟學員 PDF 講義。算附贈功能，不影響上面三位接案助理的流程，也不會被入口指令呼叫到。

工具

9 個工具：現成的技巧包，不是助理

「工具」就像工具箱裡已經做好、隨時能拿出來用的扳手或量尺：它不會自己想事情、不會自己問你問題，要有人（助理，或者你自己）拿去用，它才會動。

訪談與思考工具

pm-discovery-upgradeproject-manager 用
PM 助理分析需求前，先做一輪一題一題的前期調查，問出可以直接交給下一關使用的確認資料。
grilling通用討論工具
一題一題逼問你，直到對計畫、決策或想法有共同理解，把決策拆成一棵清楚的「決策樹」。
grill-with-docs通用討論工具
帶著既有文件跑一場逼問式訪談，邊問邊順手整理出決策記錄跟一份術語對照表。
domain-modeling通用思考工具
把一個專案要用的詞彙、概念先拆解清楚、鎖定用詞，維護一份持續更新的專案脈絡文件。

生成與計算引擎

engagement-quote報價顧問背後的引擎
把已經確認好的需求算成一份可核對的報價資料，跟一份網頁／PDF 報價單。這是報價顧問實際在用來算價格的工具，不是另一個獨立功能。
case-page跟簡報師平行的輸出路徑
把已經確認好的提案內容，做成一份網頁檔案，不用架任何伺服器、不用申請帳號，雙擊打開瀏覽器就能看。它只負責「做出這份檔案」，至於要不要放到網路上讓別人看、要不要設密碼或到期時間，交給呼叫它的人自己決定。

簡報產出（簡報師背後的兩條路）

kimi-slide簡報師的 Kimi 路徑
把素材或想法收斂成一份中繼文件，依 Kimi PPT 官方建議的格式產出提詞文字。只產出提詞，不會自己呼叫 Kimi、不會自己送出。
ppt-master簡報師的本機路徑
把交接包做成真正可以打開編輯的 .pptx 檔案，還能重建版面、管理品牌風格與版型。是一套 Python 工具，第一次用要先安裝一次需要的套件。

通用工具（不是接案專屬）

im-human語態控制／去 AI 味
把讀起來很像 AI 寫的文字，改成像人在說話。兩種用法：一種是讓 Claude 自己講話時就自然一點，另一種是幫你改寫貼文、Email、文案。只處理台灣繁體中文跟英文，不做翻譯，也不會幫你查證內容對不對。

入口指令

怎麼叫它

整案分析到報價一條龍走完，打這一行：

$ /client-quote <案件資料夾或逐字稿路徑> # 換成你的檔案路徑
  1. 串起 project-manager → commercial-proposal-quotation-specialist → 簡報師 三位助理接力
  2. 案子複雜會先多問幾輪（這步驟叫 grill-with-docs），一題一題問，答完才問下一題
  3. 需求整理完先給你看摘要，你說「對」才進報價
  4. 報價表跟網頁版你都看過、點頭，才轉成正式 PDF
  5. 報價確認完，中文跟它說「幫我做成簡報」，它自己知道要找簡報師，不用背指令

只想單獨叫某一位助理、不走整條流程：沒有現成斜線指令，直接跟它說「這次麻煩用簡報師的身分幫我」就可以，不用背指令。
